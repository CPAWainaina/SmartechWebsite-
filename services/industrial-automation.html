What We Engineer

From control concept to commissioning

Smartech can extend its electrical, power and networking capability into industrial control projects where the requirement involves machine control, remote monitoring, electrical automation or integration of existing equipment.

  • PLC-based machine and process control
  • HMI screens, alarms, trends and operator interfaces
  • SCADA and remote monitoring architecture
  • Motor control, starters and variable-speed drive configuration
  • Control and automation panel wiring, testing and documentation
  • Industrial Ethernet, fibre and control-network connectivity
  • Instrumentation, sensors and field I/O integration
  • Site testing, commissioning and technical support

Engineering Deliverables

Technical documentation that makes projects easier to build and maintain

Functional design

Control narratives, I/O schedules, sequence-of-operation documentation, alarm philosophy and system architecture for defined project requirements.

Electrical & control drawings

Panel layouts, schematics, termination schedules, control wiring diagrams and as-built documentation where included in the project scope.

Control configuration

PLC, HMI, drive and control logic configuration aligned to the approved functional requirements and available equipment.

Factory / pre-site testing

Structured inspection and functional checks before site deployment where the project requires FAT or pre-commissioning activities.

Commissioning

I/O checks, functional testing, equipment start-up support, fault finding and handover documentation for the installed system.

Support & maintenance

Planned technical support, troubleshooting and system improvement for existing electrical and automation installations.
