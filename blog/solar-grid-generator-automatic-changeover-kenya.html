What to check before replacing equipment

Adding solar to a generator-backed site creates a control problem as well as a power-generation opportunity. The system needs to know which source is available, which loads matter, what the battery SOC is and when the generator should run.

A practical control sequence

  1. Normal operation: solar supports the configured loads; grid supplies the balance where applicable.
  2. Grid outage: the system transfers or enters the designed backup mode.
  3. Battery support: selected loads are supplied from the battery within configured limits.
  4. Low SOC or prolonged outage: the controller can request generator start where supported.
  5. Generator stabilises: the transfer/control system connects the intended loads according to the designed sequence.
  6. Grid returns: the system transfers back after the required checks and the generator cools down before stopping.

Why monitoring matters

Operators should be able to answer why the generator started, what the battery SOC was, what load was present and which source supplied the site.
